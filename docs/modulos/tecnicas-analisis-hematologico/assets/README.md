# Evidencias visuales — Técnicas de análisis hematológico

Guarda las evidencias del alumnado en `docs/modulos/tecnicas-analisis-hematologico/assets/<Pxx>/`, creando cada subcarpeta al incorporar su primera imagen.

Desde una práctica, usa rutas relativas, texto alternativo y pie técnico:

```markdown
![Preparación observada en la actividad](../assets/P03/01_evidencia.jpg)

*Figura 1. Evidencia propia, autorizada y descrita con la modalidad real.*
```

No publiques nombres, rostros, etiquetas identificativas, datos personales o clínicos ni imágenes cuya captura o difusión no haya sido autorizada. Las imágenes simuladas, docentes o externas deben identificarse y citarse; no se presentan como desempeño propio.

## Recomendación práctica para el alumnado

Cada práctica incluye en su plantilla Markdown una ruta y un nombre de archivo de ejemplo para cada evidencia visual. Cuando incorpores una imagen, súbela exactamente a esa ruta y conserva el nombre indicado. Por ejemplo, si la práctica muestra:

```markdown
![Preparación observada en la actividad](../assets/P03/P03_01_preparacion.jpg)
```

debes subir la imagen a `docs/modulos/tecnicas-analisis-hematologico/assets/P03/P03_01_preparacion.jpg`. Así la imagen aparecerá automáticamente en la página publicada y se evita que quede una referencia rota. Respeta las mayúsculas, minúsculas y la extensión del archivo. Si necesitas utilizar otro nombre o formato, modifica también la ruta de la imagen en el Markdown de la práctica y comprueba la vista previa antes de confirmar los cambios.

Cada práctica debe reunir entre **5 y 8 evidencias visuales** que documenten la preparación, las fases principales del procedimiento y el resultado final. Usa imágenes autorizadas y señala si cada evidencia procede de una ejecución propia, una demostración, una simulación o documentación.
