## 4. Recursos, seguridad y autorización

**Recursos previstos:** Circuito documental con tarjetas, registros y etiquetas ficticias; nunca se procesa ni distribuye sangre. El equipo, los reactivos, los materiales y su disponibilidad deben confirmarse antes de la sesión.

**Riesgos y límites:** No procesar, conservar, etiquetar como real ni distribuir unidades. Etiquetas y códigos exclusivamente ficticios y rotulados «material docente».

> **Aviso de seguridad.** La ficha conserva el estado **SIMULATION_DEFAULT** del programa. La aprobación de diseño no autoriza por sí misma la ejecución. Si faltan PNT, evaluación de riesgos, recursos, supervisión o autorización local, utiliza exclusivamente la modalidad alternativa indicada por el profesorado.

## 5. Fundamento técnico

Los componentes sanguíneos se obtienen mediante procesos controlados y especificaciones reguladas. Una demostración de centrifugación no produce un componente validado; la trazabilidad y los controles son parte del proceso.

Las fuentes enlazadas apoyan el fundamento o el control de calidad indicado; no sustituyen el PNT del centro ni autorizan parámetros que no documenten. Si no existe un procedimiento público aplicable al producto/equipo concreto, se indica expresamente y se reserva la ejecución para una validación local.

## 6. Procedimiento y controles de calidad

### Procedimiento base

Ordena etapas → verifica identificadores ficticios → relaciona componente y destino → localiza puntos de control → analiza una desviación simulada.

### Procedimiento específico

Los pasos siguientes describen una ruta didáctica segura. Para cualquier operación húmeda, reactivo o equipo, el PNT local y las instrucciones vigentes del fabricante prevalecen; si no están confirmados, usa imagen, caso o datos simulados.

**Guía técnica de referencia para componentes sanguíneos:** [JPAC, componentes de sangre total, especificaciones y procesamiento](https://www.transfusionguidelines.org/red-book/chapter-7/7-2). JPAC describe componentes de sangre total y sus especificaciones. Se usa para analizar el circuito documental, no para producir, conservar, etiquetar o distribuir componentes; esas operaciones exigen instalaciones y procedimientos autorizados.

1. Comprueba que diagramas, unidades y etiquetas muestran «simulado» y no son utilizables clínicamente.
2. Ordena las tarjetas del circuito conforme al documento público seleccionado.
3. Relaciona cada etapa con el componente representado sin atribuir especificaciones no incluidas.
4. Comprueba continuidad de códigos ficticios entre recepción, proceso, almacenamiento y distribución.
5. Marca controles y registros que respaldan identidad y estado del componente.
6. Resuelve el escenario de discrepancia bloqueando el flujo hasta revisión simulada.
7. Explica diferencias entre plasma/hemoderivados según el alcance de la fuente usada.
8. Entrega el diagrama y destruye o archiva tarjetas según indique el docente.

### Controles de calidad

- Identificadores inventados; continuidad de trazabilidad; componentes diferenciados; puntos de control; cero datos reales.
- La fuente y la modalidad de cada imagen, registro o dato quedan identificadas.
- Los datos simulados no se presentan como resultados de paciente ni como ejecución del alumnado.
- Las incidencias, resultados no válidos y limitaciones se conservan en el registro.

JPAC describe componentes de sangre total y sus especificaciones. Se usa para analizar el circuito documental, no para producir, conservar, etiquetar o distribuir componentes; esas operaciones exigen instalaciones y procedimientos autorizados.
