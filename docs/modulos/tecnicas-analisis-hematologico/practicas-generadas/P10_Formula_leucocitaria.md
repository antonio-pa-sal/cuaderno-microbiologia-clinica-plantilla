## 6. Procedimiento y controles de calidad

### Procedimiento base

Verifica imagen y zona → clasifica con atlas → registra categorías → calcula porcentajes si corresponde → revisa discrepancias y comunica límites.

### Procedimiento específico

Los pasos siguientes describen una ruta didáctica segura. Para cualquier operación húmeda, reactivo o equipo, el PNT local y las instrucciones vigentes del fabricante prevalecen; si no están confirmados, usa imagen, caso o datos simulados.

**Fuente técnica de referencia (revisión morfológica):** [SEHH, Programa de garantía de calidad para laboratorios clínicos: revisión del frotis](https://sehh.es/images/stories/recursos/2018/08/28/PGCLC-2019.pdf). La SEHH documenta el esquema de revisión de frotis y control externo de calidad. Se usa para orientar la valoración morfológica y la comunicación; no sustituye un procedimiento local de diferencial ni autoriza emitir informes clínicos desde imágenes docentes.

1. Identifica procedencia, licencia/permiso y modalidad de cada imagen o lámina.
2. Comprueba que la zona y calidad visual permitan reconocer las características propuestas.
3. Describe primero tamaño relativo, núcleo, cromatina y citoplasma visibles.
4. Asigna una categoría usando el atlas docente autorizado y registra dudas como no clasificadas.
5. Registra el recuento indicado por el ejercicio y calcula porcentajes solo si se proporciona denominador.
6. Contrasta una selección con otra persona o clave docente y explica discrepancias.
7. Separa hallazgos morfológicos observados de interpretación didáctica.
8. Entrega la ficha sin nombres ni datos clínicos y etiqueta cualquier caso como simulado.

### Controles de calidad

- Atlas y procedencia identificados; imagen legible; denominador explícito; dudas conservadas; interpretación no diagnóstica.
- La fuente y la modalidad de cada imagen, registro o dato quedan identificadas.
- Los datos simulados no se presentan como resultados de paciente ni como ejecución del alumnado.
- Las incidencias, resultados no válidos y limitaciones se conservan en el registro.
