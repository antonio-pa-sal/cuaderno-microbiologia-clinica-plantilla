## 5. Fundamento técnico

La fragilidad osmótica estudia la respuesta de eritrocitos a medios de tonicidad decreciente. Un conjunto de datos sin método, controles, unidades y procedencia no permite validar la prueba ni inferir un cuadro clínico.

Las fuentes enlazadas apoyan el fundamento o el control de calidad indicado; no sustituyen el PNT del centro ni autorizan parámetros que no documenten. Si no existe un procedimiento público aplicable al producto/equipo concreto, se indica expresamente y se reserva la ejecución para una validación local.

## 6. Procedimiento y controles de calidad

### Procedimiento base

Audita procedencia/diseño → identifica variables y controles → grafica datos → describe tendencia → valora qué no se puede concluir.

### Procedimiento específico

Los pasos siguientes describen una ruta didáctica segura. Para cualquier operación húmeda, reactivo o equipo, el PNT local y las instrucciones vigentes del fabricante prevalecen; si no están confirmados, usa imagen, caso o datos simulados.

**Procedimiento académico de referencia (no es PNT clínico local):** [Universidad Comenius, práctica de hemólisis hipotónica; referencia docente externa, no protocolo local](https://zona.fmed.uniba.sk/uploads/media/Protocols_for_Medical_Chemistry_for_D_2020.pdf). La Facultad de Medicina de la Universidad Comenius incluye un ejercicio práctico de hemólisis hipotónica. Se enlaza como referencia educativa para comprender la curva; no valida el protocolo histórico, la muestra ni las condiciones del centro. Para el contexto de laboratorio clínico, consulta también la [descripción de la prueba del hospital universitario Sestre milosrdnice](https://klinkemija.kbcsm.hr/dobrodosli/testovi/detalji-testa/?test_id=460).

1. Confirma que la serie está autorizada para enseñanza y que no identifica personas.
2. Registra método, fuente, unidades, controles y variables que acompañan los datos.
3. Separa las observaciones entregadas de las variables no documentadas.
4. Representa los datos con ejes, unidades, leyenda y escala explícitos.
5. Describe la tendencia observada sin interpolar resultados no presentes.
6. Compara controles solo si están definidos y explica qué validación permiten.
7. Redacta una conclusión acotada y enumera la información que falta para interpretar clínicamente.
8. Marca la práctica como documental; no adaptes el guion histórico a una actividad húmeda.

### Controles de calidad

- Procedencia y versión; unidades; controles descritos; ejes rotulados; datos observados separados de inferencias.
- La fuente y la modalidad de cada imagen, registro o dato quedan identificadas.
- Los datos simulados no se presentan como resultados de paciente ni como ejecución del alumnado.
- Las incidencias, resultados no válidos y limitaciones se conservan en el registro.
