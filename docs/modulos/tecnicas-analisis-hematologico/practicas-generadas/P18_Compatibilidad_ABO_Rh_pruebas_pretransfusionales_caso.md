## 5. Fundamento técnico

La seguridad transfusional requiere identificación inequívoca, determinación de grupo, cribado de anticuerpos y pruebas pretransfusionales según procedimientos vigentes. La ficha enseña el flujo, no autoriza decisiones transfusionales reales.

Las fuentes enlazadas apoyan el fundamento o el control de calidad indicado; no sustituyen el PNT del centro ni autorizan parámetros que no documenten. Si no existe un procedimiento público aplicable al producto/equipo concreto, se indica expresamente y se reserva la ejecución para una validación local.

## 6. Procedimiento y controles de calidad

### Procedimiento base

Verifica caso y código → lee reacciones simuladas → aplica tabla docente → detecta discrepancias/controles → comunica bloqueo didáctico.

### Procedimiento específico

Los pasos siguientes describen una ruta didáctica segura. Para cualquier operación húmeda, reactivo o equipo, el PNT local y las instrucciones vigentes del fabricante prevalecen; si no están confirmados, usa imagen, caso o datos simulados.

**Guía técnica de referencia pretransfusional:** [JPAC, pruebas pretransfusionales, capítulo 13.3](https://www.transfusionguidelines.org/red-book/chapter-13-patient-testing-red-cell-immunohaematology/13-3-pre-transfusion-testing). JPAC publica recomendaciones para pruebas pretransfusionales. Se utiliza para estudiar el flujo y los puntos de seguridad en el caso simulado; el procedimiento vigente del servicio transfusional correspondiente prevalece y esta ficha no autoriza pruebas reales.

1. Confirma que el caso y todos los resultados son ficticios y codificados.
2. Comprueba correspondencia entre identidad simulada de la solicitud, muestra y componente en el ejercicio.
3. Lee las reacciones de tipificación directa/inversa y RhD según la tabla proporcionada.
4. Identifica resultados discordantes, controles faltantes o datos insuficientes antes de proponer compatibilidad.
5. Consulta la guía pretransfusional de JPAC para describir las etapas generales del laboratorio.
6. Marca cualquier discrepancia como «no resolver/consultar» dentro del caso, sin elegir componente real.
7. Registra el razonamiento, las comprobaciones y la comunicación simulada.
8. Devuelve las tarjetas didácticas y conserva la etiqueta de simulación en el producto.

### Controles de calidad

- Identificación cruzada simulada; matriz de reacciones legible; controles revisados; discrepancia escalada; conclusión no aplicable a paciente.
- La fuente y la modalidad de cada imagen, registro o dato quedan identificadas.
- Los datos simulados no se presentan como resultados de paciente ni como ejecución del alumnado.
- Las incidencias, resultados no válidos y limitaciones se conservan en el registro.
