# Cuadernos digitales de prácticas

Selecciona el módulo para abrir su cuaderno, consultar las prácticas y añadir evidencias.

## Módulos disponibles

- [Microbiología Clínica](modulos/microbiologia-clinica/index.md): cuaderno de prácticas P01–P26.
- [Técnicas de análisis hematológico](modulos/tecnicas-analisis-hematologico/index.md): cuaderno de prácticas P01–P20 del módulo 1374.

Cada módulo mantiene sus propios documentos fuente canónicos, prácticas generadas y evidencias visuales en `docs/modulos/<slug>/`.
